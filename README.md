# 🐍 Snake Game

HTML, CSS, JavaScript만으로 만든 네온 스타일 스네이크 게임입니다.
설치 없이 브라우저에서 바로 실행됩니다.

## 실행 방법

1. 저장소를 내려받습니다.
   ```bash
   git clone https://github.com/jungsooya73/snake-game.git
   ```
2. `index.html` 파일을 브라우저로 엽니다.

## 게임 규칙

- 20×20 격자 위에서 뱀을 움직여 먹이를 먹습니다.
- 먹이를 먹으면 뱀이 한 칸 길어지고 **+10점**을 얻습니다.
- 벽이나 자기 몸에 부딪히면 게임 오버입니다.
- 최고 점수는 브라우저(LocalStorage)에 저장되어 다시 열어도 남아 있습니다.

## 조작법

| 키 | 동작 |
| --- | --- |
| `↑` `↓` `←` `→` | 뱀 방향 전환 |
| `Enter` / `Space` | 게임 시작 · 다시 시작 |
| `P` / `Esc` | 일시정지 · 재개 |
| `M` | 소리 켜기 · 끄기 |

화면의 버튼으로도 시작, 일시정지, 소리 설정을 할 수 있습니다.

## 주요 기능

### 난이도 선택
게임 시작 전에 난이도를 고를 수 있습니다. 숫자는 뱀이 한 칸 움직이는 간격입니다.

| 난이도 | 이동 간격 |
| --- | --- |
| 쉬움 | 200ms |
| 보통 (기본값) | 150ms |
| 어려움 | 100ms |
| 매우 어려움 | 50ms |

### 레벨 시스템
- 50점마다 레벨이 오릅니다.
- 레벨이 오를 때마다 이동 간격이 10ms씩 줄어들어 뱀이 빨라집니다. (최소 30ms)

### 일시정지
- 게임 도중 버튼이나 `P` 키로 멈추고 다시 이어갈 수 있습니다.
- 다른 창으로 이동하면 자동으로 일시정지됩니다.

### 사운드
- 시작, 방향 전환, 먹이, 레벨업, 게임 오버, 최고 기록 달성 때 효과음이 나옵니다.
- 음원 파일 없이 Web Audio API로 직접 소리를 만듭니다.

### 그래픽
- 칸 사이를 부드럽게 미끄러지듯 움직이는 뱀 애니메이션
- 진행 방향을 바라보는 눈, 꼬리로 갈수록 가늘어지는 몸통
- 빛나는 먹이, 먹을 때 터지는 파티클과 "+10" 효과
- 게임 오버 시 화면 흔들림과 붉은 번쩍임

## 파일 구조

```
snake-game/
├── index.html   # 화면 구성 (점수판, 캔버스, 버튼)
├── style.css    # 스타일
└── main.js      # 게임 로직, 그리기, 사운드
```

## 사용 기술

- HTML5 Canvas
- CSS3
- JavaScript (외부 라이브러리 없음)
- Web Audio API
- LocalStorage
